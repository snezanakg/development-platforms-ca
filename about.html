Project Overview

This project was developed as part of the Development Platforms course at Noroff School of Technology and Digital Media.

It demonstrates the use of Supabase as a backend platform with frontend integration using HTML, CSS, and JavaScript.

Users can register, log in, and post articles that are stored securely in a Supabase database.
